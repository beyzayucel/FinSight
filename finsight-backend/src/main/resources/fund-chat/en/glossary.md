# Glossary

**Total portfolio value** — The fund's total size on the given valuation day, in Turkish lira.

**Daily return** — The fund's percentage change against the previous valuation day.

**Cumulative return** — The total percentage return built up from the start of the selected period to
the data date. It is not the plain sum of daily returns; it includes compounding.

**Benchmark** — The reference index the fund's performance is compared against.

**Benchmark gap / bps** — The difference between the fund's return and the benchmark's return, in
basis points. 100 basis points = 1%. A positive value means the fund is above its benchmark.

**Asset allocation** — The percentage split of the fund's portfolio across asset classes (equity,
bonds, deposits and so on).

**Stock breakdown** — The individual equity positions and their weights. It belongs to the portfolio
disclosure period (for example 2026-07) and is updated monthly rather than daily.

**Data date** — The valuation day all figures on the dashboard belong to.

**Period code** — An expression such as `P30D` means "the last 30 days".
